# Best Practices

✅ Always run FastAPI using Docker.

✅ Never mix host Python with Docker Python.

✅ Never manually edit PostgreSQL schema.

✅ Always use Alembic migrations.

✅ Review every autogenerated migration before upgrading.

✅ Keep Docker and host virtual environments isolated.

✅ Use Docker logs when debugging.

✅ Use `docker compose exec web sh` to run project-related commands inside the container.
